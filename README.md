# line-oa-webchat-assessment
Webchat console for LINE Official Account — receive messages via webhook and reply to users with Push API. Built with Next.js + TypeScript, deployed on Vercel.

## Getting started

```bash
cp .env.example .env.local   # fill in values
npm install
npm run dev                  # http://localhost:3000
```

Scripts: `npm run lint` · `npm run typecheck` · `npm run format` · `npm run build`

Implementation plan: [docs/implementation-plan.md](docs/implementation-plan.md)
